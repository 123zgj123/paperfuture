# 联合语料、研究 skill 与 idea 隔离

v0.5 保留原有六步主线。新增能力服务于文献检查、机制跃迁和轮间反馈，不增加隐藏候选，也不把文献维护放回每次生成过程。

## 固定两个领域，同时检索

LLM Alignment 作为第四个独立语料域，覆盖指令对齐、偏好优化、奖励学习、AI 反馈、可扩展监督及对齐失效。历史发现从 2015 年开始；历史使能工作单独查询。2025—2026 的数量、全文和检索预算均单独记录，不能把没有匹配论文的年份算作覆盖。

采集按研究分支分别查询、逐条核对来源分页计数，再计算论文 ID 的去重并集。较复杂的整段 OR 查询在实测中出现持续的服务端错误，因此 Alignment 使用 `facet_union`。元数据明确请求 arXiv v1；已被当前查询发现、且已在其他已发布语料中验证过的同版本论文可以直接复用，保存来源版本和内容哈希。限流退避保存在共享归档目录，重启或换批次不会绕过服务端的等待要求。

联合研究使用两个明确的不可变版本，例如：

```json
{
  "domain": "agent_security",
  "auxiliary_domains": ["llm_alignment"],
  "literature_mode": "frozen",
  "sources": [
    {"type": "corpus", "manifest": "/data/corpora/agent_security/releases/ID_A/manifest.json"},
    {"type": "corpus", "manifest": "/data/corpora/llm_alignment/releases/ID_B/manifest.json"}
  ]
}
```

这是配置片段；完整入口见 [联合研究示例](../examples/paperfuture/agent_security_alignment.json)。示例问题用于演示两个语料域的机制联系，不是已经生成或验证的研究结论。

每个领域独立做词法和向量召回，再通过 RRF 合并。默认每个领域至少分配 4 个初筛候选位置、2 个通过证据筛选后的选择位置和 1 个动态检索位置；示例可调整这些预算。配额只在有可用候选时生效，不让不相关、证据不足的论文绕过筛选。任一声明领域完全没有合格论文时，流程停止并留下筛选原因，而不是输出一个假称结合两领域的图。

同一论文版本跨库出现时只计为一篇，保留多个领域来源。补全文仍可选择更完整的兼容内容表示；相同版本的已有文本冲突会被拒绝。语料成员关系存放在快照侧，不修改原论文正文或内容哈希。各轮检索始终限定在这两个已冻结的版本内。

## 从 EurekAI 借鉴什么

参考了 [EurekAI](https://github.com/leehomyc/EurekAI/tree/1319c5d6dc1a39faf790f917b137d464402e358d)、它的 [eureka-idea](https://github.com/leehomyc/EurekAI/blob/1319c5d6dc1a39faf790f917b137d464402e358d/skills/eureka-idea/SKILL.md) 和 [idea-creator](https://github.com/leehomyc/EurekAI/blob/1319c5d6dc1a39faf790f917b137d464402e358d/skills/idea-creator/SKILL.md) 流程：先检查研究背景，再重述问题、检查假设、考察跨领域机制联系，并给出反例和最小实验。参考文件及 MIT 许可按这个提交归档在数据盘 `references/EurekAI/`，没有执行上游脚本。

本实现为独立编写的受约束研究流程。没有导入其 116 篇案例的拟写思考过程，没有把这类叙述当作作者的真实研究记录，也不要求模型输出长篇私人思维过程。PaperFuture 使用自己已归档的论文片段和发展图作案例来源；输出研究依据、机制比较和可证伪实验。skill 本身并不是新颖性或研究价值的证据。

| 现有步骤 | skill 的具体职责 | 可核查产物 |
|---|---|---|
| 文献筛选 | 多种术语、历史作用、最近似工作、反例、证据缺口 | 筛选漏斗、原文引用、领域配额 |
| 发展图 | 比较五维技术变化、检查实际继承关系与不确定性 | 边的原文依据、评分与独立复核 |
| 选择跃迁 | 重述瓶颈、检查关键假设、分析机制转移的适用边界 | 一个候选、因果变化、最近似工作、最小对照 |
| world model | 条件模拟、竞争解释、效用与资源混淆、区分性实验 | 独立模拟、批评、讨论、未决分歧 |
| 动态探索 | 将失败预测或成功条件映射到下一问题，显式处理经验适用性 | 分支来源、条件决策、经验迁移与短查询 |

对应的版本化文件位于 [src/paperfuture/skills](../src/paperfuture/skills)。运行保存 `skills_manifest.json`；skill 内容参与实现指纹，修改 skill 后不能悄悄恢复原实验。关闭 `research_skills.enabled` 可做同版本的流程消融，新实验需要新的 `run_id`。

## Skill 可以执行的工具

在本轮提案前，模型最多安排两次有结构的证据检查计划，总共最多 4 个工具动作（配置上限为 6）。工具由程序执行，输入范围、字符数和总调用量均校验：

- `search_papers`：在声明领域的冻结语料中分别执行 BM25，再用 RRF 合并；返回来源指针和明确标注的摘要预览。它补充初始的全库向量召回，不伪装成另一套向量检索。
- `read_passages`：读取指定论文的精确原文片段，保留版本、偏移和引文 ID。每次最多三篇，默认整轮最多额外展开 10,000 字符。
- `compare_stages`：并列检查两至三个已有阶段的机制、条件和已通过审查的关系。比较本身不创建新边，也不证明跨领域迁移成立。

工具不能访问网络、其他实验的 memory、未声明的语料、任意文件或 shell。检索结果与论文里的指令均视为数据。计划、输入哈希和结果保存在 `rounds/NN/skill_tools/`；离线审计会从同一快照重建工具结果。工具动作不生成候选，不消耗额外候选轮次，也不能突破全局最多四轮；计划请求仍计入正常 API 预算。

## 不同 idea 如何隔离

以前已经做到实验目录隔离，以及只在完全相同提示、模型和参数下共享文献准备缓存；但同一实验的提案会看到所有轮次的完整经验。v0.5 补充了候选与分支边界：

1. 每个候选由控制器赋予 `run_id`、`idea_id`、`branch_id`。读取过去候选时核对所属实验；外部实验或没有归属的候选直接拒绝。
2. `revise` 和 `continue_leap` 明确记录父候选与祖先链。条件继续成立仍是假设，不能变成已观测结果。
3. `switch` 创建新分支，自动继承条件清空。提案和检索工具规划均不接收旧分支的完整 idea 叙述；提案只收到精简的重复机制索引，以及导航显式指定的经验。
4. 完整经验默认只来自祖先链。其他记录只留下可定位的索引；导航点名后才能展开。
5. 使用祖先链之外的经验时，`memory_transfers` 必须逐条说明适用条件、条件差异、验证方法和可用证据。缺少记录会在模拟之前中断。
6. 原有 `assumption_decisions` 继续控制保留、替换或不适用。未展开的旧条件不能直接成为当前前提，已替换条件也不能用旧 ID 或简单改名偷偷恢复。

独立模拟和批评只接收当前候选及其证据；完整历史候选仅用于专门的重复检查和后续条件复核。模拟结果从不写入论文库、原文向量或历史发展图。跨实验共享的是经过验证的文献准备结果，不是 idea、模拟、批评或价值评估缓存。

`memory_scope.json`、`experience_memory.json`、`experience_index.json` 与 `proposal.json` 的迁移记录可以一起检查。程序保证归属、可见范围和引用契约；迁移理由在科学上是否成立，仍需独立评审和实验，不能靠存在一段理由就宣称完全解决语义污染。

## 验证边界

回归测试覆盖跨库去重和双侧召回、漏配语料、实验隔离、切换分支、遗漏迁移条件时停止、工具越界、调用上限以及离线审计与重放。合成测试检查软件是否遵守流程，不证明模型已经找到高价值研究。

真实效果需要等预算比较原流程、仅加 skill 指令、加有界工具、加分支隔离，以及联合／单领域检索；评估最近似工作识别、历史转折覆盖、条件迁移正确性、可证伪性和专家盲评的研究价值。这里尚未完成这组科学效果实验。
