# FarField 研究轨迹重构与论文计划

日期：2026-10-09。状态：设计与实施顺序已明确，生产重构和科研效果验证尚未完成。

本文作为后续开发与论文的主计划，替代此前以模块优化、可靠执行和榜单覆盖为中心的优先级。历史报告的实验记录、负结果与已知缺陷仍然有效，不作重写。系统目标是：从用户研究意图出发，发现有价值的研究方向，并通过真实反馈与分支内学习提高后续探索的质量。模块正确性是必要约束，模块分数不作为系统研发的最终目标。

## 研究对象重新定义

FarField 应围绕一条可追溯、可分叉的研究轨迹组织：

`研究意图 → 当前瓶颈与未知量 → 有依据的跳跃 → 落点研究与开放实现 → 真实反馈 → 分支记忆和技能更新 → 后续跳跃`

OpenWorld 维护模型对环境的可检验理解，并通过行动获取新信息；远跳利用技术演变和结构迁移提出偏离；分支学习把经历变成可复用的知识与能力。三者的联合效果，体现在未来研究的产出，而不是各自产生多少条记录。

这里有两个不同的更新对象：研究中的假设、方法和子问题，以及开展研究所需的记忆、实验程序和策略。前者是研究迭代，后者是任务内自进化。修改一个候选算法不自动意味着研究者的能力进化；积累更多提示也不自动意味着后续想法更好。本阶段不训练基础模型权重，不允许研究分支修改公共评价器或预算规则。

下一跳不必单调提高性能，也不必引入更远的领域。它可以发现新瓶颈、建立有效测量、修复实现、检验关键前提、发展方法或结束失效路线。但降低错误、压缩未知量只是过程收益，不能替代最终研究价值。

## 当前代码提供了什么基础

| 现有实现 | 可以保留的基础 | 与目标的差距 |
|---|---|---|
| `openworld/memory.py::lineage_learning` | 工作区及显式祖先链投影，不默认读取兄弟分支 | 默认回看六个祖先，动态重建；缺少分叉时固定的学习包与技能执行闭环 |
| 同函数的 `skill_candidates` | 保留来源 idea、反馈与局部作用域 | 明确为 `provisional_prompt_advice`、`executable=False`，不能称为经过验证的实验能力 |
| `discovery.py` 的分支策略版本 | 分支策略更新、安装记录及回滚边界 | 改进信号仍依赖生成式反馈，不是独立科研收益 |
| `discovery.py::_improved` | 可解释的历史启发式 | 同为 REVISE，只要失败类别改变也可计为 improvement；这只能说明反馈变化 |
| 开放执行、原生评价、结果回应与撤回 | 把研究过程接到实际程序及可追踪结果 | 工具空间、结果语义和科学确认仍有限，撤回尚未覆盖全部学习产物 |
| `extras/skills.py` 与 `openworld/evolve.py` | 已有技能文件、可信插件及局部准入代码 | 分属不同路径；文本蒸馏、受信插件、harness 修补和科研技能不能混为一类 |

本轮代码探针复现：父子反馈均为 REVISE，从 `mechanism_unsupported` 变成 `scope_mismatch` 时，当前 `_improved` 返回 true。记录见 [audit.json](../docs/audits/2026-10-09-trajectory-refocus/audit.json)。代码也将策略评价注明为生成式反馈，不能把这个代理信号直接作为论文的自进化成绩。

无需推翻当前单一运行时、事件日志和隔离执行。需要改变的是它们围绕什么状态工作、学习什么，以及如何判断学习有用。

## 架构以分支研究状态为中心

建议在现有事件运行时中增加少量有明确职责的记录，不再建立一个平行 planner 或第二套状态机。

| 记录 | 最小内容 | 作用 |
|---|---|---|
| Mission | 用户意图、用途、硬约束、价值维度、资源边界 | 防止研究逐渐变成容易得分但无关的问题 |
| BranchSnapshot | 方向、父分支、分叉事件位置、当前子问题、假设、瓶颈、学习包版本 | 固定继承边界，恢复和比较同一检查点 |
| ResearchStep | 要消除的未知量、候选解释、行动、预测、实际回执、结果回应 | 将一次研究决策连接到真实后果；不以模型调用次数定义研究跳数 |
| LearningDelta | 从哪些观测形成什么经验、适用条件、反例、尚未核验部分 | 学习的是有条件的经验，不把 critic 句子升级为事实 |
| SkillVersion | 程序／流程、输入输出合同、适用条件、来源、验证记录、版本、状态 | 支持实际调用、比较、撤回与替换 |
| CandidateSelection | 候选来源、选择理由、开发表现、最终提交身份 | 保留仍有效的 incumbent，同时如实保留新分支失败 |

上述名字是建议的数据职责，不要求按每个名字新增文件或类。能由事件推导的视图不另存一份可变真值。每次后续 idea 记录使用了哪个学习版本与具体条目，并记录执行技能版本；引用只能证明可追踪，真正贡献仍需受控实验。

### 分支隔离与继承

公共底座只读；方向空间存放有适用范围的知识；idea 分支使用自己的可写学习层。分叉从父分支的一个明确事件位置继承快照，后续写入仅影响子分支。只按 `lineage_id` 过滤提示还不够：程序文件、检索缓存、技能注册、模型会话和可变分析产物也要遵循相同权限边界。

原始只读论文或数据可以按内容哈希共享，分支对它们的解释不能自动共享。撤回事件要通知依赖该证据的所有后代；不可变快照不能成为继续使用失效依据的理由。跨分支经验迁移是显式引用与本地试用，不是把学习目录合并。最小版本先实现严格隔离和祖先继承，跨分支合并放到后续。

固定公共底座并不意味着永久禁止工程改进。工程重构由开发流程完成，版本化后再统一部署；它与研究运行内部的局部自进化分开。

### 学习对象及准入强度

一次实际反馈可产生四类东西：观察记录、暂定解释、可试用程序、得到限定验证的技能。它们的证据地位不能互换。

探索阶段允许分支试用尚未证明有益的新程序，只要求来源、适用条件和必要的执行边界；否则严格验证会再次阻止创新。试用不称作有效技能。一次技术正确的运行可证明程序能工作，但不能证明科学机制或跨任务泛化。正式确认、提升信任等级或跨分支迁移才要求更强独立验证。

技能不是新一轮预设算子全集。模型始终可以新写代码、组合、修改或拒绝已有技能。技能作用应体现为更低实验成本、新的可测量能力或更好的研究选择。仅仅使用次数变多不能构成收益。

建议状态为候选、局部试用、限定有效、停用；验证维度分别保存技术执行、测量语义、后续效用，不压成一个含糊的 admitted=true。建立技能依赖后，来源结果撤回可引发复查或停用；停用学习产物不自动否定所有下游独立实验。

## 一条最小完整轨迹应怎样工作

以下是机制说明，不是已完成的科学实验：

1. 用户给出研究意图和初始材料，系统检查材料后形成少量暂定瓶颈，允许便宜探查修改问题。
2. 首跳沿可核查的技术演变提出偏离，声明可能迁移的关系及破坏条件；缺少脉络时记录缺口并调查，不强行编造发展史。
3. 在落点附近检查类似工作和失败边界，选择值得消除的未知量，编写实际方法或建设测量工具。
4. 原生实验发现收益在等容量对照下消失。系统先检查实现和测量，再降低原有结构解释的支持，而不是宣布整个方向失败。
5. 分支保存有条件的容量混杂经验，并形成可重用的等容量对照程序；不把该经验推送到无关方向。
6. 下一跳围绕容量匹配后仍可能存在的结构收益提出新方法，调用该程序，再由独立结果判断其有效性。

贯通这一条路径比同时优化十个模块更重要。系统可以不在每一步学习；没有新信息时维护原判断并继续，避免每轮被迫蒸馏一项“经验”。

## 保留、改造、暂停和清理

| 处理 | 范围 | 原因 |
|---|---|---|
| 保留 | 单运行时、开放程序、原始回执、独立评价、任务与科学完成分离、现有分支边界 | 是研究轨迹可信和可恢复的基础 |
| 改造 | 祖先记忆改成可追溯学习快照；提示技能接可执行技能；反馈代理与实测效用分开 | 直接服务下一跳改进 |
| 改造 | critic、rollout 和研究协议按需使用，局部实现修复走短路径 | 避免每次探索都承担完整科学叙事成本 |
| 暂停扩张 | 更多 reviewer、复杂未校准 VOI、更多榜单、大规模全因子消融 | 当前尚无完整轨迹效用证据，增加模块会扩大归因困难 |
| 优先清理 | 重复 LLM 客户端、相互重叠的学习入口、重复上下文与政策来源 | 避免同一概念多种语义；先兼容迁移，确认引用后再删除 |
| 明确降级 | 脚本世界、图论 fixture、critic improvement 指标 | 保留工程回归用途，不计入主要科研能力结果 |

可靠性修复仍需完成，但限定为支持这条最小轨迹的工程门槛：预算真实记账、失败可恢复、候选不丢失、测量可定位。不能无限期停留在公共框架优化，也不能带着已知漏计和恢复错误启动长程付费实验。

## 评测以未来研究效用为主

### 主实验 A 完整研究产出

外部研究目标在运行前按领域、资源和方法开放程度分层确定。提供自然研究意图和原始材料，评价者持有验收标准及测试资源，不给模型解决路径。使用相同模型池、工具能力和总资源约束。

主对照先收敛为：强自由 agent、具有相同工具与原始历史但冻结分支学习的 FarField、完整 FarField。自由 agent 可以调试、记录笔记、重用代码，不能人为剥夺它自然学习的能力。冻结组只冻结受控的持久学习机制，不声称能够关闭基础模型全部上下文学习。

在总预算比较中，冻结组节省的整理和验证费用可以用于进一步研究，不强迫空耗。报告最终候选集合的规模及重复程度，使用固定验证额度，避免通过大量相似候选或只展示最好一项制造优势。

主要结果采用域内独立验证的成果质量与达成率，并结合盲评的研究相关性和继续投入价值。评价前定义有意义效应、任务人群和必要条件，不能事后调整成功线。新颖性、实际性能、机制证据分别报告；有效方法不自动成为新科学发现。

解释和价值判断中不能自动计算的部分，需要独立领域人员盲审，处理分歧并保留不确定性。没有这些资源时，主张只覆盖可客观验证的研究改进，不用 LLM 自评填补“科学价值”的真值。验证出边界或反例可以成为成果，但需要实质改变原有理解，不能把每次运行失败都算有价值的负结果。

### 主实验 B 同检查点的下一跳学习效应

在事前规定的研究阶段或预算位置保存真实检查点，不能只选完整 FarField 表现好的轨迹。检查点覆盖不同前缀策略；每个前缀内复制相同输入、观测、当前程序、工具状态和预算。

核心对照是继续更新／使用分支学习，与冻结同一检查点的学习版本。两组仍可取回相同原始历史并进行普通推理。进一步用相同资料的中性摘要对照和记忆／技能分别冻结的消融，区分经验组织、实际工具积累和额外上下文的收益。

复制之后允许真实轨迹分化，不应强迫两组未来获得相同结果。短窗口测下一次研究决策，较长窗口测延迟收益、失败恢复和成果质量。一次跳跃按有实际行动或证据处理的研究状态转移定义，不能用多输出几个 idea 增加样本数。

预算有两种互补口径：检查点后相同增量预算用于定位局部效应；从目标开始的总预算包括学习构建、维护与验证，用于判断实际系统收益。若比较已经构建的技能开／关，共同的构建成本在两臂都保留，并明确这是部署效应，不能冒充完整效率优势。

检查点不是独立任务；重跑、子分支、跳数也不是独立研究样本。按外部目标／原研究聚类统计，报告配对差异及不确定性。不预设每跳必然进步。

### 主实验 C 分支隔离的收益和代价

先做权限契约：子分支写入不能改变兄弟或父分支，恢复保持版本身份，失效证据能通知后代。这些是确定性工程要求。

科学效用实验比较隔离继承、共享学习池，以及后续可实现的显式验证迁移。在真实分支出现适用条件不同的经验时，测跨方向错误迁移和有效经验的可借用程度。共享对照保留相同来源与适用范围字段，只改变可见性／更新范围，避免用故意丢失语义的弱共享方案。共享检索成本和重复验证成本均计入。

隔离可能降低负迁移，也可能造成重复工作。若没有观察到污染收益，不能仅凭目录隔离正确就宣称科研质量提升。

### OpenWorld 与远跳作为联合机制消融

主实验有可归因信号后，再做有限消融。OpenWorld 关闭结构化预测和环境理解更新时，保留真实工具、观察与普通行动推理。远跳比较局部探索、普通跨域检索、脉络与机制引导；保持候选实现预算和最终验证预算一致。

最终看这些改变是否提高学习后的未来研究效用，而不是多访问了几个领域或填写了更多预测。不要一开始做模型×领域×预算×记忆×技能×隔离×远跳的巨大笛卡尔积。

## Benchmark 改为环境和材料来源

| 来源 | 保留的作用 | 不再承担的主张 |
|---|---|---|
| AgentIdeaBench | 外部主题、文献与主动检索协议；为候选提供来源 | 官方 critic 高分不能证明研究价值或自进化有效 |
| PaperBenchX | 原生实验、测量义务、部分独立检查 | 严格复现分数不等于开放创新；改动方法空间需另立扩展协议 |
| Terminal-Bench-Science | 工具与完整工作流能力检查 | 不能单凭终端任务成功率宣称更会发现想法 |
| SciFact | 证据定位和误归因回归 | 四个已用开发 claim 不再用于总体设计和泛化选型 |
| CompMat-Bench 等 | 指导强度和工作流长度的对照方法 | 尚未接入／尚未发布的资源不能计作已运行任务 |

任务必须允许真实方法改动，否则远跳被评价器的合法空间消除。外部任务若只适合复现，先用来验证执行器；不能为测试远跳而偷偷修改官方目标。跨领域通用性来自不同外部目标上相同的研究循环，不是把很多窄榜单平均成一个分数。

## 论文定位与需要证明的贡献

建议工作题目：**FarField: Branch-Scoped Learning for Open-Ended Research**。这是待证实的系统研究定位，不是已取得的成果标题。

核心研究问题：在相同基础模型、研究材料和资源约束下，限定于研究分支的经验与技能演化，能否改善后续研究决策和最终有价值的产出，并减少错误经验跨方向传播？

“记忆＋技能＋迭代”本身不能主张新颖。已有 [Voyager](https://arxiv.org/abs/2305.16291) 研究可执行技能积累，[ACE](https://arxiv.org/abs/2510.04618) 研究演化上下文，[MCE](https://arxiv.org/abs/2601.21557) 研究技能与上下文共同演化，[Memento-Skills](https://arxiv.org/abs/2603.18743) 研究基于经验的任务技能学习。[Darwin Gödel Machine](https://arxiv.org/abs/2505.22954) 已研究自改进 agent 的分支探索，[AI Scientist-v2](https://arxiv.org/abs/2504.08066) 已研究科研实验树。这些相关工作意味着，分支树与技能库的组合仍不足以自动构成创新；正式投稿前还需系统比较机制与实现。

FarField 值得检验的差异是：研究假设与开展研究的能力同时演化；学习与真实科研证据绑定，支持条件化继承及撤回；采用同检查点的未来效用实验，将自进化与普通看历史、多算几轮、提示压缩分开。三点必须由实现和对照支撑，不能仅列成架构框图。

论文组织建议：

1. **问题与动机**：研究经历未必转化为更好的后续研究；错误经验也可能扩散。用真实失败轨迹说明，不以工程测试数作论据。
2. **研究设定**：定义用户目标、研究分支、学习状态、可用反馈、预算与最终效用；明确什么不算独立科学证据。
3. **方法**：分支状态、OpenWorld／远跳如何消费反馈、学习包与可执行技能、隔离继承和撤回。
4. **评价协议**：自然输入、外部环境、同检查点分叉、总成本、公平基线、盲评与隐藏终测。
5. **主结果**：完整产出、未来学习收益、隔离的收益与代价。
6. **机制与边界**：实际使用链、远跳与 OpenWorld 消融、反例、超时和成本；完整失败日志放附录。
7. **相关工作与局限**：与上下文学习、技能学习、科研树搜索区分，讨论领域覆盖与专家评价限制。

## 可执行的重构顺序

| 阶段 | 改动与复用位置 | 退出条件 |
|---|---|---|
| R0 固定研究目标和信号语义 | 新计划；区分 critic 反馈代理、操作核验、独立结果；冻结当前基线 | 下一跳质量与论文主张都有对应外部证据，不把失败类别改变当科研改进 |
| R1 支持长轨迹的最小可靠底座 | `services/llm.py` 与 `extras/llm.py` 兼容收敛；修复账本、失败保存、恢复和局部回应 | 先前故障探针通过，完整轨迹恢复不重复执行、不丢候选；不追求无关模块最优 |
| R2 分支学习快照 | 扩展 `memory.py`、事件投影、依赖与上下文选择；保留单运行时 | 同检查点可克隆，父／兄弟不被修改，撤回传播到依赖学习条目 |
| R3 一个真实可执行技能 | 复用开放执行服务和版本化程序产物；暂不向全局插件安装 | 一项来自真实研究经历的程序在后续步骤被调用，留有来源、适用条件和独立结果 |
| R4 两到三次连续研究转移 | 联通远跳、落点调查、OpenWorld 反馈与学习版本消费 | 至少一条完整外部开发轨迹证明链路可用；不是效果或泛化结论 |
| R5 小规模配对验证 | 同检查点学习／冻结对照，计入成本；并行含义是实验条件，不要求实现多 agent | 能判断机制未生效、效果不确定或有收益；不靠更换题目掩盖负结果 |
| R6 正式评测与论文 | 锁定未参与修改的外部任务，按方差和资源确定规模 | 主结果、必要消融、盲评与失败边界齐全；之后才确定投稿主张 |

R2–R4 采用一条纵向路径逐步打通，每次修改运行受影响契约与完整轨迹回归。原有学习投影先保留兼容，等事件迁移和恢复验证完成后再清理重复代码。不可在没有真实下一跳使用的情况下，将 LearningDelta 文件存在视为功能完成。
