# Scoped experience and next-step navigation · v1

Use the current idea's memory_scope. A revision or conditional continuation has explicit ancestry. A switch starts a new branch and does not automatically inherit the old idea's premises. Prior candidates remain available for duplication checks, not as facts about the new candidate.

For each used experience outside ancestry, provide memory_transfers with its experience_id, applicability, changed conditions, evidence if available, and a discriminating test. Do not import unexpanded memory entries or experiences from another run. A prediction remains conditional even when several models agree with it.

Identify the unresolved causal issue, the variable to change and the observable pass condition. Produce short bottleneck, alternative-mechanism and falsifier queries. Explain how the lesson redirects the next location. If a lesson does not apply, record that explicitly instead of forcing its assumptions into the new idea.
