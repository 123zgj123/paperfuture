# Evidence-oriented literature inspection · v1

Identify the specific mechanism, its conditions and the strongest relevant baseline before judging an opportunity. Use several focused queries, including alternative terminology and a counterexample query. When multiple corpora are declared, search both and identify which domain supplies each premise.

Read the relevant source passages. A search preview, an unexpanded citation or an absent search result is insufficient evidence for a technical claim. Record an evidence gap when the required method or experiment is unavailable. Separate historical enabling contributions from topical similarity and preserve relevant negative results.

Deliver concise source-backed findings and explicit uncertainties. Do not invent an author's private reasoning or treat retrospective stories as experimental evidence. Query, read and comparison actions are bounded by the controller's tool budget and immutable snapshot.
