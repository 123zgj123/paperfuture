# Conditional simulation and discriminating tests · v1

Simulate the fixed proposal with its stated assumptions. Stress the strongest competing explanation, an adaptive opponent or distribution change when relevant, and the effect of matching compute, latency and legitimate task utility. Derive observable predictions for success, partial success and failure.

Compare the mechanism against the closest supplied prior work, including work the proposer omitted. Separate a demonstrated contradiction from an untested assumption or aesthetic preference. Lack of consensus is not proof that an unconventional idea lacks value. Repeated opinions from multiple models are not independent empirical observations.

Translate a disagreement into a discriminating experiment and report which condition would change the judgment. Preserve the candidate's identity during discussion: proposed repairs are feedback for a subsequent reserved round, never an unrecorded replacement idea.
